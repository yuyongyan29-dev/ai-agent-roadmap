## 心理准备

**有了 Python 基础后学 TypeScript 会比想象中快**，很多概念是相通的。

**但 CSS 和布局是另一套思维，不要低估。** 这四周的目标是「能做出可用的界面」，不是「成为前端工程师」。CSS 够用就行，遇到具体问题再查，**不要系统学**——那会吃掉你好几周。

---

## 三个关键认知

**U5.3 的 Server/Client Component 区分是最核心的概念。** 搞懂它，其余都简单。原则：**默认写 server，只把需要交互的那一小部分标成 client。**

**U5.4 是 Agent 产品和聊天框的分水岭。** 让用户看到「正在搜索…找到 23 条…正在分析…」，而不是一个转了 30 秒的圈。

**U5.5 的重点不是「怎么接登录」，而是「怎么保证数据不串」。** 三层隔离里，数据库的行级安全是兜底的那一层——它让「忘记加 WHERE user_id」这个错误在数据库层被挡住。
