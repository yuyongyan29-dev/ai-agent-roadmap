**这一阶段的核心不是学模型原理，是建立对模型行为的工程直觉**：它什么时候会错、错在哪、成本花在哪、上下文该放什么。

## 开始前的准备

**先读 [`项目结构.md`](../../docs/项目结构.md) 的第二到四节。** 它说明怎么把仓库改成 uv workspace，以及 S0 的 csvstats 项目怎么承接过来——不承接代码，承接的是目录结构、compose 配置、测试骨架和密钥管理的习惯。

**准备密钥，建议至少三家**：海外一家（Claude 或 GPT），国内两家（DeepSeek、通义、Kimi、豆包任选）。

**预算**：整个 S1 的实验大约 50 到 200 元。**先用国内的免费额度跑通流程，确认代码没问题再用付费的做对比。**

---

## 这一阶段的三个重点

**U1.5 上下文工程是最重要的一个单元。** 它是 2025 年之后 Agent 工程的核心技能，S2 到 S4 反复用到。10 小时不要压缩。

**U1.4 是你第一次做评估。** 建测试集、对比版本、用数据说话——S3 整个阶段就是把这件事做到工程级。

**U1.8 的选题决定后面所有阶段。** 选错题，S3 建不起评估集，S4 上线没人用，S5 做的界面没意义。三条硬标准逐条检验，不要将就。
