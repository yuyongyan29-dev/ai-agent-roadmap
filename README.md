# AI Agent 学习路线

> 零代码基础 → 能独立交付生产级 Agent。37 周 · 65 个单元 · 每一步都有可运行代码和验收标准。
> 依据 2026 年国内外真实招聘 JD 倒推，[网页版](https://yuyongyan29-dev.github.io/ai-agent-roadmap/)带全文搜索。

**这是什么**：一份照着做的施工图，不是资源清单。每个单元都给出能直接跑的代码、实测过的输出和明确的完成判据。

**给谁**：想转行做 AI 应用 / Agent 工程师，每周能投入 20 小时、持续大半年的人。有编程基础可以从 S1 开始，S0 只做完成判据。

## 开始

```bash
# 先 Fork，再 clone 你自己的 fork（进度和笔记会提交到你的 fork）
git clone https://github.com/<你的用户名>/ai-agent-roadmap.git ~/ai-agent-roadmap
cd ~/ai-agent-roadmap && code .
```

然后读 [`docs/开始.md`](docs/开始.md)。Windows 用户先看 [U0.1 开头的 WSL2 说明](units/s0/U0.1-命令行与开发环境.md)。

## 七个阶段

| 阶段 | 主题 | 周次 | 单元时长 | 里程碑产出 |
|---|---|---|---|---|
| S0 | 工程地基 | W1–W6 | 94h | M0 带测试和 Docker 的 REST API |
| S1 | LLM 基础与上下文工程 | W7–W10 | 68h | M1 命令行 LLM 工具 + 需求规格化能力 |
| S2 | Agent 核心 | W11–W16 | 101h | M2 你自己场景的可用 Agent |
| S3 | 评估与可观测性 | W17–W21 | 84h | M3 给 M2 建完整 eval 与 trace |
| S4 | 生产化 | W22–W27 | 88h | M4 M2 真正上线，带灰度和 SLO |
| S5 | 产品外壳 | W28–W33 | 80h | M5 Web 前端 + 小程序入口 |
| S6 | 平台与基建 + 求职 | W34–W37 | 87h | M6 mini agent runtime + 作品集 + 简历 |
| **B** | **大厂平台基建扩展**（可选） | 追加 | +36h | 见 [`扩展模块-B.md`](docs/扩展模块-B.md) |

一条主线贯穿全程：**S2 做出来的那个 Agent，S3 给它建评估，S4 让它上线，S5 给它做界面，S6 把它的运行时拆开重写一遍。** 六个里程碑不是六个玩具，是同一个东西的六次升级。

选题在 S1 结束时定下来，标准是：你自己每周真的会用、有明确的对错、涉及至少三个外部工具。详见 S1 的 U1.8。

## 三条规则

**每个单元都必须留下一个能跑的东西。** 不是笔记，是代码、能打开的页面、能贴出来的截图。

**判据没达到就不勾选。** 宁可拖一周，也不要虚勾往前赶。后面的单元建立在前面之上。

**每周留 4 小时写复盘。** 放在 `logs/`，写三件事：做出了什么、卡在哪、下周第一件事。这些日志后面直接变成面试素材。
